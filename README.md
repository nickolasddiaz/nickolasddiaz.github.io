## Install

```sh
bun install
```

## Upgrade packages

```sh
bun update --interactive
```

## Developing

start a development server:

```sh
bun run dev
```

## Building

To create a production version of your app:

```sh
bun run build
```

You can preview the production build with `bun run preview`.
